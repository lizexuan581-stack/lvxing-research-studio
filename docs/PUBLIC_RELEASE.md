# 公开版范围

这是绿行智研桌面研究工作台的独立公开代码包，保留八个桌面模块及本地计算、解析、存储、导出功能。

不包含个人证书与专利受理通知扫描件、论文全文、移动端源码、原始调研个体数据、账号凭证、录音、演示视频、参赛计划书或私有托管配置。成果中心提供研究参考与真实代码检查，不公开上述原件。

开源版未连接移动端生产后台。外部大语言模型、语义检索增强、OCR、实时市场数据、用户账户和云端多人协作不属于本次已实现范围。报告由确定性模板和人工结论组成，不是外部大模型自动撰写。

案例数据用于演示。默认排放因子、行为参数和新增订单均含明确的演示假设，不代表认证因子、模型校准或真实经营预测。对投资、碳资产核证等实际用途，仍需独立专业核验。
