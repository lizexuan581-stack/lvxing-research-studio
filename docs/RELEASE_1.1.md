# 1.1 工作台升级

## 功能

- 研究范围与政策六要素：业务分部、期间、发布者、地区、执行状态、资金承担者、生效期间和定位信息。
- 事实与假设分类：披露事实、政策目标、代理参数、情景假设及待分类；分类与原文复核状态分开。
- 碳核算逐项贡献图；行为份额按人群、频次、地域、供给和承接拆成收费/免费订单。
- 财务引擎加入固定经营费用与企业另行承担的现金激励，进入三情景、门槛与敏感性计算。
- 历史同比、毛利、毛利率、量价桥接及业务占比工具。案例载入校验来源、单位、期间、范围与复核状态。
- 最多12组财务参数快照；可比较、载入、导出。未计算的表单变更不能冒充已保存结果。
- 跟踪条件与反向证据；报告生成时保留输入快照，底稿修改后提示重新生成。
- manifest.json与逐行JSON运行记录；导入包会依据输入重算数值，不直接信任导入的结果字段。

## 兼容性

继续使用原IndexedDB数据库及工作区版本号，新增字段按默认值补齐，不清空现有资料、项目或报告。旧报告不伪装为新底稿，会提示重新生成。导入备份仍为新增研究，不覆盖现有项目。手动修改订单或使用财务预设会解除不再一致的行为映射。

## 视觉

保留墨绿、白色、浅绿配色，增加CSS分层背景、原创SVG城市线稿、路径动效和轻量图表动画。不加载外部字体、图片或动画库。支持暂停动画及prefers-reduced-motion；暂停不重置正在编辑的表单。

## 验证范围

自动化：73项规则及边界检查，另有脚本语法、许可证、私有素材排除与案例来源页码检查。

页面验收：本地浏览器实际操作政策范围保存、碳核算、行为/订单/财务联动、情景快照、历史复算、证据分类、无来源跟踪判断拦截、报告生成与过期提示、现场42项检查。公开发布还需GitHub Pages部署成功及线上页面验证。

不把上述检查表述为AI模型准确率、真实经营预测或核证减排效果。外部模型、OCR、实时行情、生产移动端后台及多人云端协作仍不在已实现范围。
